# DURAK AI — Дурак против ИИ

Браузерная игра без сервера и зависимостей: `index.html`, `style.css`, `script.js` (+ `tests.js`).

## Запуск локально
Откройте `index.html` в браузере (двойной клик) — или `python3 -m http.server 8000` и http://localhost:8000.

## На телефоне
Запустите локальный сервер на компьютере и откройте `http://<IP-компьютера>:8000` в Chrome на Android (в одной Wi-Fi сети) — либо откройте опубликованный сайт на GitHub Pages.

## GitHub Pages
1. Создайте репозиторий, загрузите три файла в корень.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>/`.

## Тесты логики
`node tests.js` — проверка правил, граничных случаев конца колоды, переводного режима, подсказок и 300 симуляций партий ИИ против ИИ.
